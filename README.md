# Plant Care Scheduler

Plant Care Scheduler adalah aplikasi untuk
mengelola jadwal penyiraman tanaman.

## Fitur

1. Menambahkan data tanaman.
2. Mengatur interval penyiraman.
3. Mencatat tanggal terakhir disiram.
4. Menghitung jadwal penyiraman berikutnya.
5. Menambahkan catatan tanaman.
6. Menghapus data tanaman.
7. Menyimpan data menggunakan Local Storage.

## Teknologi

- HTML
- CSS
- TypeScript
- Vite

## Cara Menjalankan

1. Install dependencies:

   npm install

2. Jalankan aplikasi:

   npm run dev

3. Buka alamat localhost yang ditampilkan Vite.

4. Build aplikasi:

   npm run build
